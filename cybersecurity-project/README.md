# Основы кибербезопасности — образовательный сайт

Многостраничный учебный сайт на чистых HTML, CSS и JavaScript.

## Файлы проекта

- `index.html` — главная страница и основы устройства веб-сайтов.
- `https.html` — HTTP, HTTPS, сертификаты и TLS-рукопожатие.
- `ddos.html` — DoS/DDoS, ботнеты и уровни L3/L4/L7 модели OSI.
- `protection.html` — Firewall, WAF, CDN и интерактивный тест.
- `styles.css` — единая адаптивная тема и оформление.
- `script.js` — логика теста без перезагрузки страницы.

## Запуск на компьютере

Открой `index.html` в браузере. Для локальной версии никакие библиотеки или сборка не требуются.

## Публикация через GitHub Pages

1. Создай публичный репозиторий на GitHub.
2. Загрузи в корень репозитория все HTML-файлы, `styles.css`, `script.js` и этот README.
3. Открой **Settings → Pages**.
4. В разделе сборки выбери **Deploy from a branch**, ветку `main` и каталог `/(root)`, затем нажми **Save**.
5. После завершения публикации GitHub покажет адрес сайта в разделе Pages.

Для GitHub Pages достаточно статических файлов. Отдельный сервер или база данных этому проекту не нужны. HTTPS можно включить в настройках Pages, когда домен и публикация станут доступны.

## Примечание по содержанию

Теоретическая основа взята из приложенного исследовательского проекта. Разделы WAF, CDN и краткое описание уровней OSI дополнены справочными материалами, ссылки на которые размещены на соответствующих страницах. Материал о DoS/DDoS изложен на концептуальном учебном уровне — сайт не содержит инструкций по проведению атак.
