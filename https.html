01 / БАЗОВЫЙ ПРОТОКОЛ

Что такое HTTP?

HTTP (HyperText Transfer Protocol) — протокол передачи гипертекста. Он определяет, как браузер запрашивает ресурсы, а сервер отвечает на эти запросы. HTTP работает по модели «запрос — ответ».

Например, когда ты открываешь страницу, браузер отправляет запрос GET. Сервер обрабатывает его и возвращает ответ с кодом состояния и содержимым страницы.

GETПолучить ресурс или данные.
POSTПередать данные для обработки.
200 OKЗапрос успешно обработан.
404Запрошенная страница не найдена.

Исторически HTTP развивался от простой версии HTTP/0.9 до HTTP/1.1, HTTP/2 и HTTP/3. Современные версии улучшают эффективность и скорость обмена данными.

02 / ЗАЩИЩЁННОЕ СОЕДИНЕНИЕ

Зачем нужен HTTPS?

HTTP

Открытая передача

В обычном HTTP данные передаются без встроенного шифрования. При небезопасной сети их содержимое может быть прочитано или изменено посторонним участником связи.

  • Нет шифрования трафика.
  • Нет встроенной проверки целостности на уровне TLS.
  • Нет проверки подлинности сервера с помощью TLS-сертификата.
HTTPS

Защищённая передача

HTTPS — это HTTP, работающий поверх защищённого соединения TLS. TLS помогает защитить данные от чтения и незаметного изменения при передаче.

  • Конфиденциальность — шифрование данных.
  • Целостность — обнаружение изменений.
  • Аутентификация — проверка сертификата сервера.

04 / КРИПТОГРАФИЯ

Три свойства защиты

◈

Конфиденциальность

Содержимое соединения шифруется, поэтому перехваченные данные нельзя просто прочитать как обычный текст.

✓

Целостность

Криптографическая защита позволяет обнаруживать незаметное изменение передаваемых данных.

◇

Подлинность

Цифровой сертификат помогает браузеру проверить, с каким доменом установлено соединение.
